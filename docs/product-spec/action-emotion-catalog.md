# 액션·표정 카탈로그

- 상태: 구현 기준 확정
- 카탈로그 버전: `1`
- 최종 수정: 2026-08-09
- 관련 문서: [Maple Hatch Pet MVP PRD](./mvp.md), [Pet 생성 흐름](./pet-generation-flow.md)

## 1. 계약

이 문서는 NEXON 캐릭터 이미지 API가 지원하는 액션 `A00`~`A41`과 표정 `E00`~`E24`의 고정 카탈로그다. 코드와 공식 영문명은 API 요청·로그·테스트에 사용하는 내부 계약이고, 사용자가 액션·표정을 선택하는 UI에는 한국어 표시명만 노출한다.

카탈로그 버전 `1`에서 같은 코드의 의미나 한국어 표시명을 조용히 바꾸지 않는다. NEXON 공식 계약 변경을 반영해야 하면 새 카탈로그 버전을 만들고 입력 검증, 기본값, UI와 테스트를 함께 갱신한다.

공식 영문명이 동작의 차이를 사용자에게 명확히 설명하지 않는 공격 계열은 `휘두르기 1-1`, `찌르기 2-3`처럼 안정적인 번호형 한국어 이름을 사용한다. 공식 영문명은 내부 계약에 그대로 보존한다.

## 4. 프레임 사용 규칙

- 액션은 표에 적힌 공식 프레임을 0부터 끝 번호까지 순서대로 사용한다.
- 목표 셀 수보다 공식 액션 프레임이 적으면 같은 순서를 반복한다.
- 표정 선택 UI는 전체 코드를 제공하지만 MVP 생성기는 선택한 표정의 0번 프레임만 사용한다.
- 요청에 없는 코드나 표 범위를 벗어난 하위 프레임은 허용하지 않는다.
