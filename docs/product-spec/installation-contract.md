# Pet 설치 사용자 계약

- 상태: 구현 기준 확정
- 최종 수정: 2026-08-16
- 관련 문서: [Maple Hatch Pet MVP PRD](./mvp.md), [Pet 생성 흐름](./pet-generation-flow.md), [CLI 설치 계약](./cli-installation-contract.md)

## 1. 목적과 범위

이 문서는 생성이 완료된 Codex sprite v1 Pet을 Maple Hatch Pet CLI로 설치하는 사용자 흐름을 정의한다. 패키지 형식, 검증, 로컬 경로와 오류 코드는 [CLI 설치 계약](./cli-installation-contract.md)이 소유한다.

MVP의 공식 설치 방식은 `npx maple-hatch-pet add <petId>` 하나다. 웹은 설치 명령을 표시하고 복사할 수 있게 하며, 사용자는 로컬 터미널에서 명령을 실행한다. ZIP 직접 다운로드, `curl`·`unzip`, 운영체제별 수동 설치 절차와 앱 URL 설치 방식은 제공하지 않는다.

## 2. 지원 표면

| 표면 | MVP 지원 | 설치 및 사용 방식 | 제약 |
|---|---|---|---|
| Node.js와 npm을 사용할 수 있는 로컬 환경 | 지원 | 웹에서 복사한 `npx maple-hatch-pet add <petId>`를 터미널에서 실행 | Node.js와 npm이 설치되어 있어야 하며 패키지가 만료되기 전에 네트워크로 내려받을 수 있어야 한다. |
| ChatGPT 데스크톱 앱 | 설치 결과 사용 지원 | CLI 설치 후 Settings > Pets에서 Refresh하고 설치한 Pet을 선택 | 설치 명령 자체는 앱이 아니라 터미널에서 실행한다. |
| ChatGPT 웹 | 설치 대상 아님 | 이 서비스의 CLI 설치 결과를 자동 동기화하지 않음 | 웹 업로드는 별도 제품 기능이며 Maple Hatch Pet의 설치 흐름이 아니다. |
| Codex IDE 확장 | 미지원 | 없음 | Pet 선택기와 플로팅 Pet을 제공하지 않는다. |

Node.js와 npm이 없는 사용자가 CLI 설치를 사용할 수 있다고 보장하지 않는다. MVP는 이를 위한 별도 설치 프로그램이나 수동 파일 설치 경로를 제공하지 않는다.

## 3. 설치 명령 표시

생성 성공 모달에는 다음 정보를 제공한다.

- 읽기 가능한 `npx maple-hatch-pet add <petId>` 명령
- `설치 명령 복사` 버튼
- 생성 시각부터 28일 동안 명령을 사용할 수 있다는 안내
- 터미널에서 명령을 실행하라는 안내
- 설치 후 ChatGPT 데스크톱 앱의 Settings > Pets에서 Refresh한 뒤 Pet을 선택하라는 안내
- `이미지 삭제 요청` 이메일 링크와 `닫기` 버튼

설치 모달에는 `packageUrl`, ZIP 직접 다운로드 링크, 운영체제별 명령과 수동 설치 절차를 표시하지 않는다. 설치 명령은 서버가 생성 응답으로 반환한 `installCommand`를 그대로 렌더링하며 브라우저가 `petId`로 다시 조립하지 않는다.

복사에 성공하면 같은 모달 안의 접근 가능한 상태 영역에 짧게 완료를 알리고 중복 알림을 쌓지 않는다. Clipboard API를 사용할 수 없거나 복사에 실패하면 명령을 직접 선택해 복사하라고 안내하며 설치 명령은 계속 표시한다.

## 4. 설치와 사용 흐름

1. 서버가 스프라이트 시트와 `pet.json`을 검증하고 `.codex-pet.zip`을 발행한다.
2. 웹이 생성 응답의 `installCommand`와 `expiresAt`을 설치 모달에 표시한다.
3. 사용자가 `설치 명령 복사`를 누르고 로컬 터미널에 붙여넣어 실행한다.
4. CLI가 패키지를 내려받아 검증한 뒤 현재 사용자의 Codex Pet 디렉터리에 설치한다.
5. 사용자가 ChatGPT 데스크톱 앱의 Settings > Pets에서 Refresh를 누르고 설치한 Pet을 선택한다.
6. 필요하면 명령 메뉴에서 Wake Pet을 선택하거나 `/pet`을 실행한다.

CLI가 성공을 출력하기 전에는 설치가 완료된 것으로 안내하지 않는다. 같은 `petId`를 다시 설치하면 별도 확인이나 `--force` 없이 검증된 새 패키지로 교체하며, 새 패키지의 다운로드나 검증이 실패하면 기존 설치를 보존한다.

## 5. 만료와 실패 처리

설치 명령은 생성 시각부터 28일 동안 유효하다. 만료되었거나 패키지가 이미 정리된 경우 CLI는 설치하지 않고 웹에서 현재 외형으로 Pet을 다시 생성해 새 `petId`와 명령을 받으라고 안내한다. 모든 패키지는 최대 30일 이내 삭제된다.

| 상황 | 사용자 안내 |
|---|---|
| 명령 복사 실패 | 화면의 명령을 직접 선택해 복사하도록 안내한다. |
| Node.js 또는 npm 없음 | CLI 설치를 사용할 수 없으며 Node.js와 npm이 필요한 환경임을 안내한다. |
| 패키지 만료 또는 미존재 | 웹에서 Pet을 다시 생성해 새 명령을 받도록 안내한다. |
| 네트워크 또는 저장소 장애 | 기존 설치가 있으면 보존되며 잠시 후 같은 명령을 다시 실행하도록 안내한다. |
| 패키지 검증 실패 | 설치하지 않고 패키지가 유효하지 않다고 안내한다. |
| 설치 반영 실패 | 부분 설치를 남기지 않고 기존 설치를 보존하거나 복원한 뒤 실패를 안내한다. |

삭제 요청 링크는 `mailto:1000jjj@naver.com`을 사용하고 제목을 `Maple Hatch Pet 이미지 삭제 요청`, 본문을 `삭제할 Pet ID: <petId>`로 미리 채운다. 화면에는 `packageUrl`을 별도 텍스트로 노출하지 않는다. 생성 결과는 새로고침 뒤 복원하지 않으므로 조기 삭제가 필요하면 성공 화면에서 요청한다.

## 6. 설치 완료 조건

- 생성 성공 후 같은 화면에 설치 명령, 복사 버튼, 28일 안내, 터미널 실행 안내, Pets 새로고침 안내와 이메일 삭제 요청 링크가 표시된다.
- CLI만 공식 설치 방식으로 안내하며 ZIP 직접 다운로드와 수동 설치 절차를 제공하지 않는다.
- 같은 `petId`의 재설치는 검증 성공 후 교체하고 다운로드·검증 실패 시 기존 설치를 보존한다.
- 설치 성공 후 ChatGPT 데스크톱 앱에서 Refresh한 뒤 설치한 Pet을 선택할 수 있다.
- Node.js와 npm이 없는 환경의 설치를 보장하지 않는다는 제약이 명시된다.
